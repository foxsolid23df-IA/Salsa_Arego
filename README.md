# Salsas Arego - Menú Virtual 🌶️

Bienvenido al repositorio oficial de **Salsas Arego**, una aplicación web diseñada para mostrar nuestro delicioso menú de salsas caseras y conectar con nuestros clientes.

## 📋 Descripción del Proyecto

Este proyecto es el sitio web oficial de Salsas Arego, donde los clientes pueden:
- Explorar nuestro catálogo de salsas ("Nuestros Sabores").
- Ver una galería de platillos disfrutados por nuestra comunidad ("Antojos Arego").
- Contactarnos directamente vía WhatsApp para pedidos o para compartir sus fotos.

## 🚀 Tecnologías Utilizadas

- **HTML5**: Estructura semántica y moderna.
- **CSS3**: Diseño responsivo, estilos personalizados y animaciones suaves.
- **JavaScript**: Lógica para cargar el menú dinámicamente y manejar interacciones.
- **Font Awesome**: Íconos vectoriales para una interfaz visual atractiva.
- **Google Fonts**: Tipografía 'Poppins' para asegurar legibilidad y estilo.

## 📂 Estructura del Proyecto

El proyecto está organizado de la siguiente manera para facilitar su mantenimiento y escalabilidad:

```
Salsas Arego/
├── css/             # Estilos y hojas de cascada (style.css)
├── img/             # Recursos de imágenes (logos, productos, placeholders)
├── js/              # Lógica de la aplicación (script.js)
├── index.html       # Página principal
└── README.md        # Documentación del proyecto
```

## 🛠️ Instalación y Uso

Este es un sitio web estático, por lo que no requiere instalación de dependencias de servidor.

1.  **Clonar el repositorio:**
    ```bash
    git clone https://github.com/foxsolid23df-IA/Salsa_Arego.git
    ```
2.  **Abrir el proyecto:**
    Navega a la carpeta del proyecto y abre el archivo `index.html` en tu navegador web de preferencia (Chrome, Firefox, Edge, etc.).

## 📱 Funcionalidades Clave

- **Menú Dinámico:** La sección de catálogo está preparada para cargar productos mediante JavaScript.
- **Integración con WhatsApp:** Botones flotantes y de llamada a la acción ("Subir mi Foto") que redirigen a WhatsApp para una comunicación directa.
- **Diseño Responsivo:** Adaptado para visualizarse correctamente en móviles, tablets y escritorio.
